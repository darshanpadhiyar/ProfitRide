# **App Name**: Blinkit Delivery Earning Tracker Pro

## Core Features:

- Secure User Authentication: Allow users to register and log in securely via phone (OTP) or email and password. Includes session management and logout functionality.
- Dashboard Summary: Display real-time summaries for today, week, and month including earnings, total orders, distance, online hours, fuel cost, other expenses, and net profit. Presented in a clean, mobile-first card layout with relevant icons.
- Delivery and Expense Entry System: Enable users to add, edit, or delete detailed entries including date, orders, earnings, distance, online hours, tips, and manual expenses. Includes a separate section for tracking other expenses like food and maintenance.
- Automated Fuel Cost Calculation: Allow users to configure petrol price and bike mileage. Automatically calculates fuel used and cost for each delivery based on distance. Provides real-time fuel cost and profit updates during entry, with an option for manual override.
- Advanced Analytics Dashboard: Visualize key metrics like earnings vs expenses, fuel cost trends, and net profit trends using interactive charts. Also displays calculated metrics such as earnings per km/hour/order and fuel cost per km.
- AI Smart Insights Tool: Provide a tool to predict next day's earnings based on past performance, suggest optimal working hours, detect days with potential losses, and offer personalized advice like estimated savings from mileage improvements.
- Data Export and Reporting: Generate comprehensive daily, weekly, and monthly reports that can be exported in PDF or CSV formats.

## Style Guidelines:

- Overall color scheme: Dark. This choice emphasizes data clarity and readability, especially beneficial for a dashboard with analytical content, reducing eye strain during prolonged use typical for financial tracking applications. The darker background allows bright data visualizations and UI elements to pop, enhancing user focus.
- Primary accent color: #38B2FF. This vibrant yet sophisticated blue is chosen to evoke trust, clarity, and reliability. It will be used for key interactive elements, important metrics, and to highlight positive financial outcomes like net profit, signifying growth and effective management.
- Background color: #21282B. A deep, desaturated blue-grey to provide a calm and focused environment, allowing data and primary UI elements to stand out prominently while maintaining visual continuity with the primary accent. This background forms a cohesive canvas for complex information.
- Secondary accent color: #85EDFF. An energetic cyan, analogous to the primary blue but with significantly higher brightness and saturation. This color is ideal for call-to-action buttons, interactive chart highlights, and notifications, providing a strong visual contrast to guide user attention and convey immediacy.
- Primary font: 'Inter' (sans-serif). Chosen for its modern, objective, and highly legible design, making it suitable for both headlines and body text across a data-rich application. Its neutrality ensures focus remains on the financial data and insights, supporting readability on mobile screens.
- Use a consistent set of line-style or minimalist filled icons. Integrate the requested specific icons like '₹' for currency, '⛽' for fuel, '📦' for orders, and '📍' for distance, maintaining a clean and intuitive visual language across the application for quick comprehension.
- Implement a mobile-first responsive layout with an emphasis on single-hand usability. Utilize clean card-based components for grouping related information, big touch-friendly buttons for easy interaction, and clear hierarchy to simplify navigation and data consumption.
- Incorporate subtle and quick animations for data updates on dashboards, state changes in input fields, and smooth transitions between views. Animations should be performant and not distract from the primary data, serving to provide gentle visual feedback to user actions.
