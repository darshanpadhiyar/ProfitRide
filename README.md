# ProfitRide: Delivery Earning Tracker

**ProfitRide** is a financial analytics suite specifically designed for Indian delivery partners (Blinkit, Swiggy, Zomato). It transforms earnings data into actionable insights, providing a smart dashboard for income optimization.

## 🚀 Product Overview
The application solves the pain point of manual record-keeping for gig workers by providing a centralized dashboard for earnings, tips, incentives, and expenses. It calculates real-time net profit by auditing fuel costs against mileage and manual expenses.

## ✨ Core Features

### 1. AI-Powered Smart Entry
- **Vision Extraction**: Upload a screenshot of the delivery app earnings page; the AI (Gemini 2.5 Flash) extracts Orders, Earnings, Incentives, and Login Hours.
- **2026 Protocol**: The AI automatically assumes the year 2026 for all extracted dates unless specified otherwise.
- **Precise Time Logging**: Users log work duration using separate **Hours** and **Minutes** fields for intuitive data entry.
- **Integrity Check**: The system prevents duplicate logs for the same date to ensure data accuracy.

### 2. Dashboard
- **Period Matrix**: Toggle between Day, Week, and Month views.
- **Strict 7-Day Logic**: Weekly calculations use precise interval filtering.
- **KPI Tracking**: Real-time display of Gross Revenue, Tips, Incentives, Distance, Work Time, and Net Profit.
- **Progressive Goals**: Visual progress bars for Daily Earning Goals and Order Milestones.

### 3. AI Insights
- **Efficiency Audit**: AI suggests mileage improvements and identifies loss days.
- **TTS Integration**: AI insights can be read aloud using high-quality Text-to-Speech.

### 4. Attendance
- **Calendar View**: Highlights days worked.
- **Reliability Profile**: Tracks active days to build a professional work profile.

### 5. Data Management
- **Pro Export**: Generates a high-fidelity CSV report including advanced metrics like Profit Margins and Expense breakdowns.
- **Cloud Sync**: All data is secured and synchronized via Firebase in real-time.
